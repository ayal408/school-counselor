# כלי הליווי החדשים

## עדכון התקנה קיימת

ב־PowerShell, מתיקיית הפרויקט:

```powershell
git checkout dev
git pull origin dev
.\scripts\start-local.ps1
```

ללא תעודת רשת מקומית: `docker compose up --build -d`.
מיגרציה 0006 רצה עם עליית counselor-server. אינה מוחקת פגישות או תלמידות. כרטיסים קיימים מקבלים את שנת הלימודים הנוכחית (ספטמבר–אוגוסט). מפתחות ההצפנה של ההתקנה הקיימת צריכים להישאר זמינים כדי לקרוא את התיעוד הקיים.

## בכרטיס התלמידה

- **פגישה חדשה:** תבנית ראשונה / מעקב / הורים, נושא, נושאים שעלו, תיעוד, סיכום, החלטות וצעדי המשך.
- **טיוטה:** נשמרת מוצפנת בשרת מדי שנייה לאחר שינוי, גם בזמן עריכת פגישה. אפשר לסגור ולפתוח כדי להמשיך. אין שמירת תיעוד ב־localStorage. לכל פגישה ולתיעוד חדש טיוטה נפרדת. שינוי מקביל בחלון אחר יוצר שגיאת התנגשות ולא דריסה.
- **אישור:** יוצר פגישה או גרסה חדשה באופן אטומי ומוחק את הטיוטה שאושרה. תמלול אוטומטי מחייב בדיקה ואישור היועצת. טיוטה שלא אושרה יכולה להישמר אוטומטית.
- **גרסאות:** בכל פגישה אפשר לראות מי ערכה, מתי ואת התיעוד בכל גרסה. תיעוד ישן ללא זהות עורכת מוצג כך במפורש. היסטוריה אינה נמחקת בעריכה. טיוטות ביניים אינן גרסאות מאושרות.
- **החלטות למשימות:** יצירת משימה עם מועד יעד. אותה החלטה באותה גרסה אינה יוצרת משימה כפולה.
- **הורים וצוות:** תיעוד מועד, סוג קשר, שם, שיחה ותיאומים.
- **תוכנית ליווי:** מטרות (מטרה בכל שורה), מדד ומועד יעד; עדכוני התקדמות, הערות ומצב. עדכוני תוכנית נשמרים בהיסטוריה.

## הסכמות והרשאות

יש לתעד בנפרד הסכמה להקלטה, לתמלול, לעיבוד אצל ספק מסוים ולשיתוף עם יועצת מסוימת, כולל מועד, תוקף ומקור האישור. התיעוד אינו מחליף את האישור הנדרש לפי מדיניות המוסד.

השרת בודק הסכמה תקפה לפני הרשאת הקלטה ולפני העברת שמע לתמלול. ספק חיצוני מחייב בנוסף הסכמה לספק שנבחר. יצירת סיכום מטקסט מחייבת הסכמה לעיבוד אצל הספק, אך אינה דורשת הסכמה להקלטה שלא בוצעה.

שיתוף לצפייה תלוי בהסכמה תקפה בכל בקשת נתונים. **שיתופים קיימים יפסיקו להקנות גישה עד לתיעוד הסכמה תקפה ליועצת המקבלת.** ביטול או פקיעה מונעים בקשות חדשות; אין אפשרות לבטל מידע שכבר נקרא בעבר.

העברת ליווי דורשת הסכמה לשיתוף עם המקבלת, סיסמה (ואימות דו־שלבי אם הופעל), ולאחר מכן קבלה מפורשת ב״חיפוש, דוחות ושנת לימודים → העברות ליווי״. המקבלת מאשרת עם סיסמתה. קבלה מעבירה בעלות וכל התיעוד והטיוטות; השיתופים הקודמים מבוטלים. נבדקת חפיפה ביומן המקבלת. אפשר לדחות או לבטל בקשה ממתינה.

## חיפוש, דוחות ושנת לימודים

- חיפוש לפי חלק משם, כיתה, נושא, טווח פגישות ומשימות פתוחות. התוצאות מוגבלות לכרטיסים שהמשתמשת מורשית לראות.
- דוחות אישיים ללא שמות, מזהי כרטיסים, כיתות או טקסט חופשי: מספר פגישות ותלמידות, נושאים חוזרים והתקדמות ממוצעת במטרות. הדוח מוצג רק כשיש לפחות 5 תלמידות עם פגישות בטווח. גם נושא והתקדמות מוצגים רק על בסיס 5 תלמידות לפחות. נתונים מצרפיים אינם מבטיחים אנונימיות בכל הקשר; אין פילוח לקבוצות קטנות.
- מעבר שנה: בחירת תלמידות בבעלות היועצת, כיתה חדשה או סימון מסיימת, בדיקת הרשימה ואישור בסיסמה. המעבר הוא לשנה העוקבת בלבד ובפעולה אטומית. מסיימות נכנסות לארכיון, שיתופיהן מבוטלים ופגישות מתוכננות שלהן החל מ־1 בספטמבר של שנת היעד מבוטלות. כל התיעוד והמשימות נשמרים. נשמר גם תיעוד של הכיתה והשנה הקודמות.

## הקלטה ללא סיכום AI

הקלטה ותמלול ידני זמינים גם ללא ספק AI. נגן השמע תומך בהשהיה, שינוי מהירות וחזרה 10 שניות. ההקלטה נשארת בזיכרון הדפדפן ואינה נשמרת לאחר סגירה. התמלול הכתוב נשמר כחלק מהטיוטה המוצפנת.

אפשר לבחור ״תמלול אוטומטי בלבד״ ללא יצירת סיכום, או ״תמלול וסיכום״. אין יצירת סיכום אוטומטית ללא לחיצה נוספת.

## תמלול מקומי אופציונלי

זיהוי דיבור מקומי באמצעות faster-whisper הוא עדיין מודל למידת מכונה, אך אינו שולח תוכן לספק חיצוני. השירות נפרד, ללא פורט פומבי וברשת Docker פנימית ללא גישה החוצה. אין מעבר אוטומטי לענן כאשר השירות נכשל. השמע מפוענח בזיכרון; היישום אינו כותב קובץ שמע לדיסק. מגבלות: 20MB, עד 10 דקות, בקשת זיהוי אחת בכל פעם.

להכנה חד־פעמית במחשב עם גישה מאושרת להורדת מודל:

```powershell
python -m pip install huggingface-hub==0.36.0
python scripts/download-transcription-model.py
```

הסקריפט מוריד את Systran/faster-whisper-small אל `models/whisper` (התיקייה אינה נכנסת ל־Git). ברשת מסוננת יש להגדיר את תעודת הרשת גם עבור Python, או להוריד במחשב מורשה ולהעתיק את התיקייה. השירות עצמו משתמש רק בתיקייה המקומית במצב offline; ההורדה אינה מתבצעת בזמן תמלול.

עם NetFree:

```powershell
.\scripts\start-local.ps1 -LocalTranscription
```

ללא תעודת רשת מקומית:

```powershell
docker compose -f docker-compose.yml -f compose.local-transcription.yml up --build -d
```

נדרש מקום למודל ולתלויות וזיכרון פנוי (מגבלת השירות 3GB). זמן העיבוד תלוי בחומרה. זמינות המודל נבדקת לפני שהאפשרות נפתחת בממשק. מדריך המקור: https://github.com/SYSTRAN/faster-whisper

## גיבוי ובדיקות

גיבוי מוצפן כולל עכשיו גם תיעוד מובנה, גרסאות מאושרות, טיוטות, תוכניות והיסטורייתן, קשרי הורים וצוות, הסכמות ושנת לימודים. הגיבוי קורא גם ארכיוני גרסה 1. שחזור מוסיף כרטיסים חדשים; שיתופים אינם משוחזרים והסכמות שיתוף מיובאות מבוטלות. מפתחות ספקים וחשבונות משתמשות אינם חלק מהגיבוי האישי.

בדיקות השרת מכסות הרשאות, הצפנה, התנגשות גרסאות, הסכמות, העברה, מעבר שנה, דוחות ושחזור. חיבורי ספקים ותמלול מקומי נבדקים עם תעבורה מדומה ללא מידע אמיתי. יש לבדוק את איכות התמלול בעברית עם המודל והחומרה של ההתקנה לפני הסתמכות עליו.

## הכתבה בדפדפן כמו chatapp-next

במסך תיעוד פגישה מופיע כפתור ״התחלת הכתבה בדפדפן״. משתמש ב־SpeechRecognition / webkitSpeechRecognition, כמו `ayal408/chatapp-next/src/hooks/useSpeechRecognition.ts`, עם שפה קבועה he-IL. אינו דורש מפתח API, מודל Whisper או יצירת סיכום. הוא הכתבה חיה מהמיקרופון; אינו ממיר קובץ הקלטה קיים.

נדרשת תמיכת דפדפן, הרשאת מיקרופון והסכמות תקפות להקלטה, לתמלול ולזיהוי בדפדפן. הסכמת ״זיהוי דיבור בדפדפן״ זמינה בלשונית ההסכמות, והיא כוללת אפשרות לעיבוד חיצוני: הדפדפן רשאי להפעיל שירות רשת משלו, ולכן האפשרות אינה מסומנת כמקומית או מובטחת ללא אינטרנט. אין שליחת שמע ל־API של ספקי AI מטעם היישום במסלול זה.

טקסט סופי בלבד מתווסף לתיעוד הקיים ונשמר בטיוטה המוצפנת. לפני פרסום נדרש אישור היועצת. עצירה, יציאה מהמסך פקיעת ההסכמה או תום 10 דקות מפסיקים את ההכתבה. לא מופעל fallback לספק AI אם זיהוי הדפדפן נכשל. תמלול Whisper מקומי נותר אפשרות נפרדת למי שזקוקה לזיהוי ללא שירות חיצוני.


## עריכת כרטיס, משימות והדפסה

בעלת הכרטיס יכולה לערוך שם, כיתה וסיבת הפניה. עריכה שולחת את הפרטים המקוריים: אם הם השתנו בחלון אחר, השרת מחזיר התנגשות במקום לדרוס אותם. ניתן להחזיר תלמידה מארכיון; שנת הלימודים והכיתה נשמרות, ופגישות שבוטלו או שיתופים שהוסרו אינם חוזרים אוטומטית.

מסך המשימות כולל מונים למשימות פתוחות, באיחור ולהיום, חיפוש בתיאור וסינון לפי תלמידה, טווח מועד וסטטוס. משימות של כרטיסים בארכיון מוסתרות כברירת מחדל. עריכת תיאור, מועד או סטטוס בודקת את הערכים המקוריים כדי למנוע דריסת עדכון מקביל. קוראת עם שיתוף אינה יכולה לערוך משימות.

בכל פגישה יש קישור לתצוגת הדפסה של הפגישה הנוכחית בלבד. שם וכיתה מוצגים רק לאחר בחירה מפורשת; טקסט חופשי עדיין עשוי להכיל פרטים מזהים. אפשר לבחור שמירה כ־PDF בחלון ההדפסה של הדפדפן. השרת בודק הרשאה והסכמת שיתוף בתוקף ומתעד את פתיחת תצוגת ההדפסה ביומן הביקורת.
