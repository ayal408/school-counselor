# מערכת ניהול ליועצת בית הספר

פרויקט חדש למערכת פנימית בעברית לניהול תלמידות, תיעוד פגישות ומעקב, עם הקלטה, תמלול וסיכומי AI באישור היועצת.

## אפיון

[מסמך האפיון בעברית](docs/specification.he.md)

## מצב הפרויקט

שלב אפיון. טרם מומשו האתר, ההזדהות, אחסון הנתונים או חיבור AI. אין להזין מידע אמיתי על תלמידות לפני יישום ובדיקת דרישות האבטחה והפרטיות שבאפיון.

## סדר הפיתוח

1. תשתית, הרשאות וניהול תלמידות.
2. כרטיס תלמידה, יומן, תיעוד ידני ומשימות.
3. הקלטה בהסכמה, תמלול עברי וסיכום כטיוטה לאישור.
4. בדיקות הרשאות, גיבוי ושחזור לפני שימוש במידע אמיתי.
